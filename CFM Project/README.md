# Computing for Mathematics Module Final Project - YahtzeeAid

Raw Code for my Computing for Mathematics project. The coding was largely done by me (please see the contributions file for my submission). Also the longest project I have ever done. 

## Description

A simulator library for a single turn of Yahtzee, and then can perform Monte Carlo simulations of said turn in order to find the move the highest expected value, or highest chance of obtaining a specific hand.
